# Типы событий и уровни важности для EventJournal

Этот файл описывает минимальный согласованный набор типов событий и уровней важности,
используемых компонентом `EventJournal` и системой Analytics.

## Уровни важности (severity)

- `info` — стандартные информационные события (приём заказа, изменение статуса, успешные операции).
- `warning` — потенциально проблемные ситуации, не приводящие к немедленной остановке сервиса.
- `error` — ошибки обработки, из‑за которых операция не была успешно завершена.
- `security` — события, связанные с безопасностью (нарушения политик, подозрительная активность).
- `audit` — события, фиксирующие значимые управленческие действия (подписание договора, изменение конфигурации).

## Базовые типы событий (event_type)

### Заказы и предложения

- `order_received` — Эксплуатант принял заказ от Агрегатора.
- `proposal_calculated` — рассчитано предложение по стоимости выполнения заказа.
- `proposal_submitted` — предложение отправлено Агрегатору.
- `order_accepted` — заказ принят к исполнению.
- `order_rejected` — заказ отклонён.

### Парк БАС

- `fleet_uas_reserved` — БАС зарезервирован под заказ.
- `fleet_uas_released` — БАС освобождён.
- `fleet_uas_purchased` — новый БАС куплен у Разработчика.
- `fleet_status_updated` — изменён статус БАС или парка.

### Миссии и НУС

- `mission_created` — миссия создана планировщиком.
- `mission_validated` — миссия проверена на ограничения ОрВД/зон.
- `mission_started` — миссия запущена.
- `mission_completed` — миссия успешно завершена.
- `mission_aborted` — миссия прервана.

### Безопасность

- `security_violation` — зафиксировано нарушение политики безопасности.
- `security_request_denied` — запрос отклонён монитором безопасности.
- `security_audit` — создана запись аудита по результатам проверки.

### Интеграции

- `aggregator_request` — входящий запрос от Агрегатора.
- `insurer_quote_requested` — запрошена страховая котировка.
- `insurer_quote_approved` — страховая котировка одобрена.
- `insurer_quote_denied` — страховая котировка отклонена.
- `gcs_mission_requested` — Эксплуатант запросил построение миссии у НУС.
- `gcs_mission_provided` — НУС вернул рассчитанную миссию.

### Специализированные события для агродрона

- `agro_order_received` — получен аграрный заказ (обработка/опрыскивание поля).
- `agro_uas_selected` — выбран агродрон для выполнения заказа.
- `agro_mission_planned` — построена миссия для аграрной задачи.
- `agro_mission_completed` — миссия агродрона успешно завершена.
