# Реализация Change Request #1: Интеграция с Регулятором и Разработчиками БАС

## Обзор изменений

Реализована интеграция системы Эксплуатант с Регулятором и Разработчиками БАС для автоматизации процесса покупки беспилотных авиационных систем.

## Выполненные задачи

### 1. ✅ Создание клиента для взаимодействия с Регулятором
- **Файл**: `src/regulator_client.py`
- **Функциональность**:
  - Регистрация оператора в системе Регулятора
  - Получение списка зарегистрированных систем и их топиков
  - Поддержка тестового режима через переменные окружения

  - Поиск подходящих моделей по требованиям
  - Оформление заказов на покупку БАС

### 3. ✅ Создание тестовых данных
- **Файл**: `data/developers_catalog.yaml`

## Ключевые особенности реализации

### Режимы работы
1. **Тестовый режим** (по умолчанию):
   - Использует переменные окружения для топиков
   - Загружает каталоги из YAML файла
   - Не требует реальных внешних систем

2. **Продуктивный режим**:
   - Получает топики от Регулятора через API
   - Запрашивает каталоги у реальных Разработчиков
   - Полная интеграция с внешними системами

### Безопасность
- Все внешние взаимодействия проходят через Security Monitor
- Валидация данных на всех уровнях
- Логирование всех операций

### Расширяемость
- Легко добавлять новых разработчиков
- Поддержка различных категорий БАС
- Гибкая система требований для поиска

## Использование

### Запуск тестов
```bash
# Все тесты
pipenv run pytest

# Только юнит-тесты
pipenv run pytest tests/unit/

# Только интеграционные тесты
pipenv run pytest tests/integration/
```

### Запуск демонстрации
```bash
# Запустить Jupyter notebook
pipenv run jupyter notebook notebooks/uas_purchase_demo.ipynb
```

### Генерация диаграмм
```bash
# Установить PlantUML
pipenv install

# Сгенерировать PNG из PUML файлов
python -m plantuml docs/diagrams/*.puml
```

## Переменные окружения

Для тестового режима используются следующие переменные:
- `AGGREGATOR_ID` - ID системы Агрегатора
- `DEVELOPERS_IDS` - Список ID разработчиков (через запятую)
- `INSURANCE_IDS` - Список ID страховых компаний
- `UTM_ID` - ID системы ОрВД
