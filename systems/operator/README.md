# Система Эксплуатант (Operator System)

## Описание

Система Эксплуатант - ключевой компонент экосистемы управления беспилотными авиационными системами (БАС), обеспечивающий безопасную обработку заказов на доставку грузов, управление парком БАС и планирование миссий.

## Архитектура

Система построена на принципах Security by Design с многоуровневой архитектурой безопасности:

```
┌─────────────────────────────────────────────────────────────┐
│                    Внешние системы (D3)                      │
│                  ┌─────────────────────┐                     │
│                  │   Operator System   │                     │
│                  └──────────┬──────────┘                     │
├─────────────────────────────┼───────────────────────────────┤
│              Операционный уровень (D2)                       │
│                  ┌──────────┴──────────┐                     │
│                  │   Business Logic    │                     │
│                  └──────────┬──────────┘                     │
├─────────────────────────────┼───────────────────────────────┤
│                 Доверенный уровень (D1)                      │
```

## Компоненты

### 1. Security Monitor (D0_CRITICAL)
- Централизованная проверка всех запросов
- Реализация политик безопасности
- Логирование нарушений
- Контроль потоков данных

### 2. Fleet Manager (D1_TRUSTED)
- Управление парком БАС
- Резервирование и освобождение БАС
- Мониторинг состояния
- Проверка готовности к полёту

### 3. Mission Planner (D1_TRUSTED)
- Планирование маршрутов
- Валидация миссий
- Взаимодействие с ОрВД
- Оптимизация полётов

### 4. Business Logic (D2_OPERATIONAL)
- Расчёт стоимости
- Создание предложений
- Интеграция со страховыми
- Контроль рентабельности

### 5. Operator System (D3_EXTERNAL)
- Координация компонентов
- Обработка внешних запросов
- Управление заказами
- Сбор статистики

## Политики безопасности

1. **P1: Authorized Operators Only** - только авторизованные операторы
2. **P2: Valid Mission Parameters** - валидация параметров миссии
3. **P3: Profitability Check** - минимальная маржа 10%
4. **P4: Valid UAS Certificate** - действующие сертификаты БАС
5. **P5: Data Flow Control** - контроль потоков между доменами

## API

### Основные действия

#### Управление заказами
- `RECEIVE_ORDER` - получение заказа от Агрегатора
- `CALCULATE_PROPOSAL` - расчёт коммерческого предложения
- `SUBMIT_PROPOSAL` - отправка предложения
- `ACCEPT_ORDER` - принятие заказа
- `REJECT_ORDER` - отклонение заказа

#### Управление миссиями
- `PLAN_MISSION` - планирование миссии
- `START_MISSION` - запуск миссии
- `COMPLETE_MISSION` - завершение миссии
- `GET_MISSION_STATUS` - статус миссии

#### Управление парком
- `GET_FLEET_STATUS` - статус парка БАС
- `RESERVE_UAS` - резервирование БАС
- `RELEASE_UAS` - освобождение БАС

## Мониторинг

### Prometheus
Метрики доступны на http://localhost:9090:
- Количество обработанных заказов
- Статистика по миссиям
- Состояние парка БАС
- Нарушения безопасности

### Grafana
Дашборды доступны на http://localhost:3000:
- Обзор системы
- Статус компонентов
- Метрики производительности
- Журнал безопасности
