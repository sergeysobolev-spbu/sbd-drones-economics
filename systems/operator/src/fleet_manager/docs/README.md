# Fleet Manager Component

## Описание

Fleet Manager - компонент системы Эксплуатант, отвечающий за управление парком беспилотных авиационных систем (БАС). Компонент реализован с использованием принципов минимизации доверенных доменов безопасности.

## Архитектура

Компонент разделен на два домена безопасности:

### 1. Доверенный домен (D1_TRUSTED) - FleetManagerCore
- Минимальный код для критичных операций
- Авторизация операций с БАС
- Атомарные операции резервирования/освобождения
- Управление критичным состоянием БАС

### 2. Недоверенный домен (D2_OPERATIONAL) - FleetManagerService
- Бизнес-логика и оптимизации
- Интеграция с внешними системами
- Аналитика и метрики
- Логирование и мониторинг

## Основные функции

### Управление парком
- Отслеживание состояния всех БАС
- Резервирование БАС для миссий
- Контроль готовности к полёту
- Мониторинг сертификатов и обслуживания

### Оптимизация выбора БАС
- Поиск подходящих БАС по требованиям миссии
- Расчёт рейтинга пригодности
- Учёт расположения и заряда батареи
- Прогнозирование необходимости обслуживания

### Интеграция с системами
- Взаимодействие с Регулятором для проверки сертификатов
- Получение каталогов от Разработчиков
- Покупка новых БАС
- Синхронизация топиков через Регулятора

## API компонента

### Основные команды

#### GET_UAS_LIST
Получение списка всех БАС в парке.

**Запрос:**
```json
{
  "action": "GET_UAS_LIST",
  "sender": "component_id"
}
```

**Ответ:**
```json
{
  "uas_list": [...],
  "total": 10,
  "statistics": {...}
}
```

#### FIND_AVAILABLE_UAS
Поиск доступных БАС для миссии.

**Запрос:**
```json
{
  "action": "FIND_AVAILABLE_UAS",
  "payload": {
    "requirements": {
      "type": "light_cargo",
      "min_payload": 3.0,
      "min_range": 20.0,
      "min_battery": 0.5
    }
  }
}
```

#### RESERVE_UAS
Резервирование БАС для миссии.

**Запрос:**
```json
{
  "action": "RESERVE_UAS",
  "payload": {
    "uas_id": "UAS-001",
    "mission_id": "MISSION-123",
    "duration": 3600
  }
}
```

## Конфигурация

### Переменные окружения
- `COMPONENT_ID` - идентификатор компонента (по умолчанию: fleet_manager_01)
- `BROKER_TYPE` - тип брокера (mqtt/kafka)
- `BROKER_HOST` - хост брокера
- `BROKER_PORT` - порт брокера
- `FLEET_MANAGER_TOPIC` - топик компонента

### Файлы конфигурации
- `resources/config.yaml` - основная конфигурация
- `resources/security_goals.yaml` - цели безопасности

## Развертывание

### Локальный запуск
```bash
cd systems/operator/src/fleet_manager
python -m fleet_manager
```

### Docker
```bash
docker build -t fleet_manager:latest -f docker/Dockerfile .
docker run -e BROKER_HOST=broker fleet_manager:latest
```

## Безопасность

Компонент реализует следующие меры безопасности:
- Разделение на доверенные и недоверенные домены
- Минимизация кода в критичных функциях
- Валидация всех входных данных
- Атомарность критичных операций
- Аудит всех операций
