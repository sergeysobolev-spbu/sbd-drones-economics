\begin{frame}[fragile]{Ограничения и допущения (Stage 2)}
\begin{itemize}
  \item Только Mosquitto как брокер MQTT (без кластеризации, без внешних шардов).
  \item 20--40 БВС одновременно; ОрВД шлёт почти real-time команды: \texttt{pause}, \texttt{abort}, обновления NFZ/плана.
  \item MQTT v5 предпочтителен (TTL через expiry), но допускается v3.1.1 при явной обработке \texttt{ttl\_ms} на клиентах.
  \item Требуются демонстрируемые меры ИБ: mTLS, ACL, аудит.
\end{itemize}
\end{frame}

% 5
\begin{frame}[fragile]{Целевая архитектура (логическая)}
\begin{itemize}
  \item ОрВД (publisher команд, subscriber событий)
  \item БВС (subscriber команд, publisher событий/телеметрии)
  \item Mosquitto (центральный брокер)
  \item OPS/Мониторинг (subscriber событий/статусов, опционально)
\end{itemize}
\vspace{1em}
Ключевой принцип: пер-дроновая изоляция команд/событий + глобальные рассылки для NFZ.
\end{frame}

% 6
\begin{frame}[fragile]{Интерфейсы и направления трафика}
\begin{itemize}
  \item ОрВД $\rightarrow$ Mosquitto: команды \texttt{cmd/*}, глобальные \texttt{global/cmd/*}
  \item БВС $\rightarrow$ Mosquitto: события \texttt{evt/*}, статусы \texttt{status/*}
  \item Mosquitto $\rightarrow$ БВС: команды \texttt{cmd/*}, глобальные \texttt{global/cmd/*}
  \item OPS $\leftarrow$ Mosquitto: телеметрия/алерты/статусы
\end{itemize}
\end{frame}

\begin{frame}[fragile]{Общий envelope сообщения (для всех схем)}
\small

\begin{Verbatim}[fontsize=\scriptsize, baselinestretch=0.85]

  "schema": "string",        // e.g. "uas.cmd.pause.v1"

% 21
\begin{frame}[fragile]{Корреляция, идемпотентность, дедупликация}
\begin{itemize}
  \item Каждая команда имеет \texttt{msg\_id}; ACK ссылается на неё через \texttt{ref\_msg\_id}.
  \item Борт хранит последние N \texttt{msg\_id} (например 256) + время, отбрасывает дубликаты.
  \item Для QoS 1 допускаются повторы: обработка команды должна быть идемпотентной.
  \item Для telemetry/position (QoS 0) дедуп обычно не нужен.
\end{itemize}
\end{frame}

\toprule
Тип & QoS & Retained & Комментарий \\

% 23
\begin{frame}[fragile]{Retained: правила (что можно, что нельзя)}
\begin{itemize}
  \item Retained = \textbf{только} для состояния, которое должно быть актуально при новом подключении:
  \begin{itemize}
    \item \texttt{v1/global/cmd/nfz.update}
    \item \texttt{v1/uas/<id>/status/conn}
  \end{itemize}
  \item Retained \textbf{нельзя} для команд \texttt{pause/abort} (риск исполнения устаревшего).
  \item Для retained payload обязателен \texttt{version} и/или \texttt{hash}.
\end{itemize}
\end{frame}

% 24
\begin{frame}[fragile]{TTL/Expiry: правила почти real-time команд}
\begin{itemize}
  \item MQTT v5: выставлять \texttt{Message Expiry Interval} (например 2 сек) на \texttt{pause/abort}.
  \item MQTT v3.1.1: дублировать \texttt{ttl\_ms} в envelope и отбрасывать на борту.
  \item Если команда просрочена: ACK \texttt{REJECTED} с причиной \texttt{expired}.
\end{itemize}
\end{frame}

% 25
\begin{frame}[fragile]{Ошибки, повторы, таймауты (контракт)}
\begin{itemize}
  \item ОрВД ждёт \texttt{ACCEPTED} для \texttt{pause/abort} не дольше порога (см. тесты).
  \item При отсутствии ACK: повтор публикации 1 раз (QoS1) \textit{только если TTL не истёк}.
  \item БВС обязан быть безопасным автономно: при потере связи $\rightarrow$ failsafe (RTB/loiter/land) по политике.
\end{itemize}
\end{frame}

% 26
\begin{frame}[fragile]{Безопасность: mTLS (минимум для Stage 2)}
\begin{itemize}
  \item Брокер: TLS listener, проверка клиентского сертификата.
  \item Идентичность клиента: CN или SAN $\rightarrow$ \texttt{clientid}/ACL \texttt{\%c}.
  \item Запрет анонимных подключений, запрет downgrade на plaintext.
  \item Артефакты: сертификаты тестовых БВС/ОрВД, журнал подключений, результаты негативных тестов.
\end{itemize}
\end{frame}

% 27
\begin{frame}[fragile]{Безопасность: ACL (изоляция per-UAS)}
\small
Пример \texttt{mosquitto.acl}:
\begin{verbatim}
pattern read  v1/uas/%c/cmd/#
pattern write v1/uas/%c/evt/#
pattern readwrite v1/uas/%c/status/#

topic read v1/global/cmd/nfz.update

user orvd
topic write v1/uas/+/cmd/#
topic read  v1/uas/+/evt/#
topic read  v1/uas/+/status/#
\end{verbatim}
Требование: БВС не может читать/писать чужие \texttt{v1/uas/<id>/...}.
\end{frame}

% 28
\begin{frame}[fragile]{Наблюдаемость и аудит}
\begin{itemize}
  \item Mosquitto: включить логирование подключений/отключений, авторизацию, ошибки публикаций.
  \item Клиенты: логировать публикацию команд, получение команд, публикацию ACK.
  \item Собирать метрики:
  \begin{itemize}
    \item latency: \texttt{cmd publish} $\rightarrow$ \texttt{ack ACCEPTED}
    \item потери: доля команд без ACK
    \item rate: messages/sec на telemetry/position
  \end{itemize}
  \item Артефакты тестов: \texttt{broker.log}, \texttt{client.log}, \texttt{pcap}, сводный отчёт.
\end{itemize}
\end{frame}

\begin{frame}[fragile]{Тест-стратегия: уровни}
\begin{itemize}
