# Задача 1

проанализируй реализации систем в каталоге systems, задокументируй отклонения от ТЗ, описанного в docs/requirements_spec.md, подготовь план интеграции систем для этапа 0.

Этап 0 должен обеспечивать взаимодействие Заказчика с Агрегатором, Агрегатора с Эксплуатантом, Эксплуатанта со Страховой Компанией, НУС, Дронопортом, ОрВД БВС. Должна быть возможность заказать услугу обработки полей агро-дроном.
