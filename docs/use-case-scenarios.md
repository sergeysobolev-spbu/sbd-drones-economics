# Детализированные сценарии использования

## Общие принципы для всех сценариев

### Цели безопасности
1. **Предотвращение столкновений** - БАС не должен сталкиваться с препятствиями или другими БАС
2. **Соблюдение воздушного пространства** - БАС должен находиться только в разрешённых зонах
3. **Контролируемое поведение** - БАС должен выполнять только авторизованные команды
4. **Безопасное завершение** - При любых нештатных ситуациях БАС должен безопасно прекратить миссию
5. **Защита данных** - Конфиденциальность и целостность передаваемой информации

### Экономические принципы
- Минимальная маржа эксплуатанта: 10%
- Страховые премии зависят от уровня безопасности
- Штрафы за нарушение целей безопасности
- Бонусы за безаварийную эксплуатацию

## Сценарий 1: Опрыскивание полей (AGR)

### Описание
Агродрон выполняет обработку сельскохозяйственных угодий химическими препаратами с точным дозированием и контролем зон распыления.

### Участники
- **Заказчик**: Фермерское хозяйство
- **Агрегатор**: Платформа агроуслуг
- **Эксплуатант**: Компания агродронов
- **БАС**: Специализированный агродрон с системой распыления
- **Дронопорт**: Полевая база с запасом химикатов

### Предусловия
- БАС имеет действующий сертификат для агроопераций
- Химические препараты одобрены и имеют паспорт партии
- Погодные условия соответствуют требованиям (ветер < 5 м/с)
- Определены границы обрабатываемых участков

### Основной поток

#### 1. Формирование заказа
```json
{
  "order_id": "ORD-AGR-2024-001",
  "customer": "farm-001",
  "type": "CROP_SPRAYING",
  "area_hectares": 50,
  "chemical": "HERBICIDE-X",
  "concentration": 2.5,
  "target_zones": [
    {"id": "field-1", "geometry": {...}, "crop": "wheat"},
    {"id": "field-2", "geometry": {...}, "crop": "corn"}
  ],
  "no_spray_zones": [
    {"id": "water-1", "geometry": {...}, "type": "water_source"},
    {"id": "road-1", "geometry": {...}, "type": "public_road"}
  ],
  "deadline": "2024-03-20T18:00:00Z",
  "safety_requirements": {
    "max_wind_speed_ms": 5,
    "min_temperature_c": 10,
    "max_temperature_c": 25,
    "no_rain_hours": 6
  }
}
```

#### 2. Выбор исполнителя
- Агрегатор рассылает запросы эксплуатантам с подходящими БАС
- Эксплуатанты проверяют:
  - Наличие свободных агродронов
  - Запас нужного химиката
  - Возможность выполнить в срок
- Расчёт стоимости:
  ```
  Базовая стоимость = площадь × тариф_за_га
  Стоимость химиката = объём × цена_за_литр
  Операционные расходы = время_полёта × стоимость_час
  Страховка = базовая_ставка × коэффициент_риска
  Итого = (Базовая + Химикат + Операционные + Страховка) × 1.1
  ```

#### 3. Планирование миссии
НУС создаёт оптимальный маршрут:
- Разбивка поля на полосы (ширина захвата распылителя)
- Расчёт точек разворота
- Определение зон дозаправки химикатом
- Буферные зоны вокруг запретных участков (мин. 10м)
- Точки включения/выключения распыления

```json
{
  "mission_id": "MIS-AGR-2024-001",
  "flight_plan": {
    "takeoff_point": {"lat": 55.123, "lon": 37.456},
    "spray_segments": [
      {
        "segment_id": 1,
        "start": {"lat": 55.124, "lon": 37.457},
        "end": {"lat": 55.124, "lon": 37.467},
        "spray_on": true,
        "flow_rate_l_min": 2.5,
        "altitude_m": 3,
        "speed_ms": 5
      }
    ],
    "refill_points": [
      {"id": "refill-1", "after_segment": 25, "location": {...}}
    ],
    "landing_point": {"lat": 55.123, "lon": 37.456}
  }
}
```

#### 4. Получение разрешений
- Запрос в ОрВД БАС с планом полёта
- ОрВД проверяет:
  - Отсутствие конфликтов с другими БАС
  - Соответствие высотным ограничениям
  - Отсутствие временных запретных зон
- Выдача разрешения с временным окном

#### 5. Предполётная подготовка
- Загрузка химиката в бак (с фиксацией партии)
- Калибровка системы распыления
- Проверка метеоусловий
- Загрузка полётного задания
- Проверка целей безопасности

#### 6. Выполнение миссии
БАС выполняет полёт с постоянным контролем:
- **Геозоны**: Модуль безопасности блокирует распыление вне целевых зон
- **Дозирование**: Контроль расхода химиката (±5% от заданного)
- **Высота**: Поддержание 3-5м над культурой для оптимального покрытия
- **Скорость**: 4-6 м/с для равномерного распределения

Телеметрия включает:
```json
{
  "telemetry_type": "AGR_SPRAY",
  "timestamp": "2024-03-16T10:15:30.123Z",
  "position": {"lat": 55.124, "lon": 37.462, "alt_m": 3.2},
  "spray_status": {
    "active": true,
    "flow_rate_l_min": 2.48,
    "pressure_bar": 3.2,
    "tank_level_l": 45.3,
    "coverage_m2": 12500
  },
  "environmental": {
    "wind_speed_ms": 3.2,
    "wind_direction_deg": 270,
    "temperature_c": 18.5
  }
}
```

#### 7. Завершение и отчётность
После посадки формируется отчёт:
- Фактически обработанная площадь
- Расход химиката по зонам
- Карта покрытия с GPS-треками
- Любые отклонения от плана
- Экологические параметры во время работы

### Альтернативные потоки

#### A1: Усиление ветра во время миссии
1. Датчики фиксируют превышение допустимой скорости ветра
2. Модуль безопасности автоматически отключает распыление
3. БАС переходит в режим ожидания (loiter) на безопасной высоте
4. Если ветер не стихает 5 минут - возврат на базу
5. Миссия помечается как частично выполненная

#### A2: Обнаружение людей в зоне обработки
1. Система технического зрения обнаруживает человека
2. Немедленное отключение распыления
3. Увеличение высоты до 20м
4. Отправка алерта оператору
5. Ожидание команды продолжить/прервать

#### A3: Отказ системы распыления
1. Обнаружение аномального расхода/давления
2. Прекращение распыления
3. Фиксация GPS-координат места отказа
4. Возврат на базу для обслуживания
5. Уведомление о необходимости дообработки

### Метрики успешности
- **Точность покрытия**: ≥95% целевой площади
- **Экономия химиката**: ≤5% перерасход
- **Безопасность**: 0 инцидентов распыления вне зоны
- **Своевременность**: Выполнение в агротехнические сроки

## Сценарий 2: Инспекция инфраструктуры (INSP)

### Описание
БАС выполняет визуальную и сенсорную инспекцию критической инфраструктуры (ЛЭП, трубопроводы, мосты) с соблюдением безопасных дистанций.

### Участники
- **Заказчик**: Инфраструктурная компания
- **Эксплуатант**: Компания промышленных инспекций
- **БАС**: Инспекционный дрон с камерами и сенсорами
- **Аналитик**: Специалист по обработке данных инспекции

### Предусловия
- БАС оборудован необходимыми сенсорами (RGB, тепловизор, лидар)
- Определены объекты инспекции и критические точки
- Согласованы безопасные дистанции до объектов
- Получены допуски для работы вблизи инфраструктуры

### Основной поток

#### 1. Формирование задания на инспекцию
```json
{
  "inspection_id": "INSP-2024-001",
  "infrastructure_type": "POWER_LINE",
  "objects": [
    {
      "id": "tower-001",
      "type": "transmission_tower",
      "location": {"lat": 55.234, "lon": 37.567},
      "inspection_points": [
        {"id": "insulator-1", "type": "insulator", "priority": "high"},
        {"id": "conductor-1", "type": "conductor", "priority": "medium"}
      ]
    }
  ],
  "requirements": {
    "image_resolution_cm_px": 0.5,
    "thermal_sensitivity_c": 0.1,
    "min_standoff_distance_m": 5,
    "weather_limits": {
      "max_wind_speed_ms": 10,
      "min_visibility_m": 1000
    }
  }
}
```

#### 2. Планирование маршрута инспекции
НУС создаёт план с учётом:
- Оптимальных углов съёмки для каждой точки
- Безопасных дистанций (электромагнитные поля, турбулентность)
- Освещённости для качественной съёмки
- Последовательности облёта для минимизации времени

```json
{
  "inspection_plan": {
    "waypoints": [
      {
        "id": "wp-001",
        "position": {"lat": 55.234, "lon": 37.567, "alt_m": 50},
        "gimbal_angle": {"pitch": -30, "yaw": 0},
        "sensors": ["rgb_camera", "thermal"],
        "hover_time_s": 10,
        "standoff_m": 7
      }
    ],
    "safety_volumes": [
      {
        "type": "cylinder",
        "center": {"lat": 55.234, "lon": 37.567},
        "radius_m": 5,
        "height_m": 100,
        "restriction": "no_fly"
      }
    ]
  }
}
```

#### 3. Выполнение инспекции
БАС выполняет облёт с активным контролем:
- **Дистанция**: Лидар/радар контролирует расстояние до объекта
- **Стабилизация**: Компенсация ветра для чёткой съёмки
- **Сбор данных**: Синхронная запись с всех сенсоров
- **Метаданные**: GPS-привязка каждого снимка

Специальная телеметрия:
```json
{
  "inspection_telemetry": {
    "current_object": "tower-001",
    "current_point": "insulator-1",
    "standoff_distance_m": 6.8,
    "data_quality": {
      "image_sharpness": 0.92,
      "thermal_snr": 45,
      "gps_accuracy_m": 0.3
    },
    "anomalies_detected": [
      {
        "type": "hot_spot",
        "location": "insulator-1-phase-b",
        "temperature_delta_c": 15.3,
        "confidence": 0.87
      }
    ]
  }
}
```

#### 4. Обработка результатов
- Автоматическая сортировка данных по объектам
- Предварительный анализ на борту (детекция аномалий)
- Формирование отчёта с привязкой к схеме объекта
- Сравнение с предыдущими инспекциями

### Альтернативные потоки

#### B1: Обнаружение критической аномалии
1. ИИ-модуль обнаруживает опасный дефект
2. Автоматическая фиксация дополнительных ракурсов
3. Немедленная отправка алерта заказчику
4. Продолжение инспекции с повышенным вниманием

#### B2: Электромагнитные помехи
1. Потеря/искажение GPS-сигнала вблизи ЛЭП
2. Переход на визуальную навигацию
3. Увеличение дистанции до объекта
4. Использование RTK-поправок

#### B3: Динамическое препятствие
1. Обнаружение птицы/другого дрона
2. Остановка и оценка траектории
3. Маневр уклонения с сохранением безопасной зоны
4. Возврат к прерванной точке инспекции

### Метрики успешности
- **Полнота инспекции**: 100% критических точек
- **Качество данных**: ≥90% снимков пригодны для анализа
- **Обнаружение дефектов**: ≥95% известных аномалий
- **Безопасность**: 0 нарушений минимальной дистанции

## Сценарий 3: Доставка ценных грузов (CARGO)

### Описание
БАС осуществляет доставку ценных/критичных грузов с полным контролем цепочки поставок и защитой от несанкционированного доступа.

### Участники
- **Отправитель**: Медицинская организация
- **Получатель**: Удалённая клиника
- **Эксплуатант**: Служба дрон-доставки
- **Страховая**: Специализированная страховая для ценных грузов
- **Дронопорты**: Точки отправки и получения

### Предусловия
- Груз соответствует ограничениям по весу и габаритам
- Оформлена страховка на полную стоимость
- Получатель подтвердил готовность принять
- Грузовой отсек БАС имеет систему контроля доступа

### Основной поток

#### 1. Регистрация груза
```json
{
  "cargo_id": "CARGO-MED-2024-001",
  "type": "MEDICAL_URGENT",
  "description": "Вакцины COVID-19",
  "value_usd": 50000,
  "weight_kg": 2.5,
  "dimensions_cm": {"l": 30, "w": 20, "h": 15},
  "requirements": {
    "temperature_c": {"min": 2, "max": 8},
    "max_g_force": 3,
    "delivery_window": {
      "start": "2024-03-16T14:00:00Z",
      "end": "2024-03-16T16:00:00Z"
    },
    "chain_of_custody": true,
    "tamper_evident": true
  },
  "sender": {
    "id": "hospital-central",
    "contact": {...},
    "location": {...}
  },
  "recipient": {
    "id": "clinic-rural-001",
    "contact": {...},
    "location": {...},
    "auth_code": "encrypted_auth_code"
  }
}
```

#### 2. Оценка рисков и страхование
Страховая компания анализирует:
- Стоимость груза
- Маршрут (населённые пункты, водоёмы)
- Погодные условия
- История эксплуатанта
- Уровень защиты БАС

Расчёт премии:
```
Базовая ставка = 0.5% от стоимости
Коэффициент маршрута = 1.2 (над населёнными пунктами)
Коэффициент погоды = 1.0 (хорошие условия)
Коэффициент безопасности = 0.8 (сертифицированный БАС)
Премия = 50000 × 0.005 × 1.2 × 1.0 × 0.8 = $240
```

#### 3. Подготовка к отправке
В дронопорте отправления:
1. Проверка температуры в грузовом отсеке
2. Размещение груза с фиксацией
3. Активация датчиков (температура, удары, вскрытие)
4. Опечатывание электронным замком
5. Фотофиксация состояния

```json
{
  "loading_record": {
    "timestamp": "2024-03-16T13:45:00Z",
    "operator": "staff-001",
    "cargo_condition": "sealed_intact",
    "compartment_temp_c": 5.2,
    "lock_id": "LOCK-789",
    "lock_status": "armed",
    "photos": ["hash1", "hash2", "hash3"],
    "witnesses": ["staff-001", "security-001"]
  }
}
```

#### 4. Выполнение доставки
БАС выполняет полёт с усиленным контролем:
- **Маршрут**: Отклонение < 50м от утверждённого
- **Высота**: Минимум 100м над населёнными пунктами
- **Скорость**: Оптимальная для минимизации времени
- **Мониторинг**: Непрерывный контроль состояния груза

Расширенная телеметрия:
```json
{
  "cargo_telemetry": {
    "compartment_status": {
      "temperature_c": 5.1,
      "humidity_pct": 45,
      "pressure_hpa": 1013,
      "vibration_g": 0.8,
      "lock_status": "armed_locked"
    },
    "security_events": [],
    "estimated_arrival": "2024-03-16T14:35:00Z",
    "fuel_margin_pct": 35
  }
}
```

#### 5. Процедура передачи
В дронопорте получения:
1. Верификация получателя (биометрия + код)
2. Проверка целостности пломб
3. Контроль температурного режима
4. Разблокировка замка только после подтверждения
5. Фотофиксация и подпись получателя

```json
{
  "delivery_confirmation": {
    "timestamp": "2024-03-16T14:37:00Z",
    "recipient_verified": true,
    "verification_method": ["face_recognition", "auth_code"],
    "cargo_condition": "intact",
    "temperature_log": {
      "min_c": 4.8,
      "max_c": 5.4,
      "avg_c": 5.1
    },
    "recipient_signature": "digital_signature_hash",
    "photos": ["hash4", "hash5", "hash6"]
  }
}
```

### Альтернативные потоки

#### C1: Попытка несанкционированного доступа
1. Датчик фиксирует попытку вскрытия
2. Немедленная блокировка замка
3. Отправка алерта всем участникам
4. Включение маяка и сирены
5. Автоматический возврат на ближайшую безопасную базу

#### C2: Отклонение от маршрута
1. GPS фиксирует отклонение > 100м
2. Проверка причины (ветер, препятствие)
3. Если не обосновано - команда вернуться на маршрут
4. При невыполнении - экстренная посадка
5. Активация режима охраны груза

#### C3: Критическое изменение условий хранения
1. Температура выходит за пределы
2. Попытка стабилизации (изменение высоты)
3. Если не помогает - поиск ближайшей точки передачи
4. Уведомление о риске порчи груза
5. Экстренная процедура передачи

### Метрики успешности
- **Сохранность**: 100% грузов доставлены без повреждений
- **Своевременность**: 95% в пределах временного окна
- **Температурный режим**: 100% соблюдение для медицинских грузов
- **Безопасность**: 0 случаев несанкционированного доступа

## Общие принципы обработки нештатных ситуаций

### Приоритеты безопасности
1. **Безопасность людей** - избегание populated areas при аварийной посадке
2. **Сохранность БАС** - минимизация повреждений
3. **Выполнение миссии** - только если не противоречит п.1 и п.2
4. **Экономическая эффективность** - оптимизация при соблюдении безопасности

### Уровни реагирования
1. **Информирование** - логирование события, продолжение миссии
2. **Предупреждение** - уведомление оператора, готовность к действиям
3. **Вмешательство** - изменение параметров миссии
4. **Прерывание** - контролируемое завершение с возвратом
5. **Экстренная посадка** - немедленная посадка в ближайшей безопасной точке

### Документирование инцидентов
Каждый инцидент должен быть задокументирован:
- Точное время и место
- Условия возникновения
- Предпринятые действия
- Результат
- Рекомендации по предотвращению

Это обеспечивает непрерывное улучшение системы безопасности и накопление опыта для обучения ИИ-модулей.
