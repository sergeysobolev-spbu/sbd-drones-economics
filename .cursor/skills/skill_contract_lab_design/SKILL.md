# Skill Contract Lab Design

## Use When

Use for course labs, student assignments, instructor notes, rubrics, scaffolds and assessment for Fabric, broker contracts and EventJournal traceability.

## Workflow

1. Select learning level: basic OП, advanced OП or KТ research track.
2. Define observable skills: run, read, modify, test, explain and trace.
3. Provide scaffold, expected artifact and common failure modes.
4. Add rubric: correctness, traceability, negative test, evidence and explanation.
5. Keep infrastructure load bounded for classroom use.
6. Escalate module scope and mandatory/optional status to the teacher.

## Output Contract

```markdown
## learning_scope
## target_zun
## lab_steps
## expected_artifacts
## rubric
## troubleshooting
## human_review
## next_step
```
