# РБПО ↔ жизненный цикл ↔ шаблоны СКИБ

Краткая матрица для `skill_systems_engineer_sbd`. **РБПО** (ГОСТ Р 56939-2024) применяется на стыке реализации и сопровождения; **не заменяет** ранние артефакты СКИБ (КБП, ЦПБ, АП, ДВБ).

## Этапы ЖЦ и фокус

| Этап ЖЦ (`task.md`) | СКИБ (приоритет) | РБПО (если есть код/конвейер) |
|---------------------|------------------|--------------------------------|
| 1–2 Замысел, контекст | Ш1, Ш2 | — |
| 3–4 Требования, архитектура | Ш3, Ш6, Ш7 | задел: security requirements в backlog |
| 5 Проектирование деталей | Ш7, Ш8 | threat-informed design, secure coding guidelines |
| 6–7 Реализация, интеграция | Ш14, Ш15, Ш16 | ревью, SAST, unit/security tests, SBOM, CI gates |
| 8–9 Эксплуатация, сопровождение | Ш9, Ш11, Ш18 | патчи, дельта ПСПО, мониторинг, PDCA |

## Типовые артефакты РБПО

| Артефакт | Связь с СКИБ |
|----------|-------------|
| Security requirements в backlog | трассировка к ЦБ из ЦПБ |
| Чек-лист ревью безопасности | правила архитектуры политики (Ш7) |
| SAST / линтеры / DAST | негативные проверочные сценарии (Ш8) |
| SBOM, дельта ПСПО | доверенная база, Ш14–Ш16 |
| Отчёт security-тестов | матрица трассировки (Ш8, `skill_traceability`) |
| PDCA после инцидента | `skill_incident_bridge` |

## Когда не включать РБПО

- старт КБП/ЦПБ без кода;
- чисто организационный или ConOps-анализ (достаточно школ СИ + Ш1–Ш3);
- TOC-сессия по ограничениям деятельности.
