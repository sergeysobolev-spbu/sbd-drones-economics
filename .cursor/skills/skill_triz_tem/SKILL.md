# Skill TRIZ TEM

## Workflow

1. Define one conflict per pass.
2. Build a function model.
3. Formulate a technical or physical contradiction.
4. State the ideal final result.
5. Propose 1-3 solution directions with evidence or experiments.
6. Mark claims as `fact`, `hypothesis` or `requires_human_review`.
