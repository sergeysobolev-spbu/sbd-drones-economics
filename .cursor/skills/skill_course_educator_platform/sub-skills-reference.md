# Sub-skills: методист и преподаватель

Детализация для `skill_course_educator_platform`. Реестр: `docs/ai_sbd/agents/course_educator/course_educator_skills_v1.yaml`.

## skill_curriculum_architecture

**Методист.** Структура курса: темы, часы, последовательность, спираль (например У-10 → У-9 → У-5 → У-2), различие **МК** (методология, Essence, ревью) vs **ПИКС** (инжиниринг, C4, CI).

**Выход:** тематический план, карта тем, gate-точки (ДЭ0…ДЭ3), список рисков перегруза.

## skill_zun_artifact_trace

**Методист.** Матрица «тема → коды ЗУН → артефакт → метод проверки». Согласование с приложением А в `ksa_v2.md`.

**Выход:** таблица трассировки, пробелы покрытия, ссылки на шаблоны Ш1–Ш18 где уместно.

## skill_lab_and_project_design

**Методист + преподаватель.** Лабораторные, СР, шаблоны П1–П5, работа со стендом ТЭМ, контракты между командами.

**Выход:** описание работы, входы/выходы, минимальный прогон, связь с `make ci-unit-test`.

## skill_lesson_session_design

**Преподаватель.** Сценарий занятия: цели, тайминг, активности, демо, разбор ошибок, домашнее задание.

**Выход:** план занятия, speaker notes, чек-лист материалов, резерв при сбое стенда.

## skill_assessment_rubric

**Преподаватель + методист.** Рубрика, контрольные вопросы, итоговая, peer review, связь баллов с артефактами (не gamification-баллы сами по себе).

**Выход:** рубрика с уровнями, образцы принятия/отклонения, апелляционная логика.

## skill_teaching_pdca

**Методист.** Опросы, карты здоровья проекта (Essence), ретроспектива потока, список изменений на следующий семестр.

**Выход:** PDCA-цикл, приоритеты доработки УМК, гипотезы для проверки.
